# Contributing

Bug reports and focused improvements are welcome through [GitHub Issues](https://github.com/Rimoros/mindgym/issues) and pull requests.

For a bug report, include the browser, steps to reproduce, expected behavior, and actual behavior. Avoid including personal browser-progress exports unless necessary and deliberately shared.

For a code change, describe the problem and resulting behavior, edit the root source files, refresh `dist/` with `npm run build`, and run `npm test` and `npm run check`. Follow the [development guide](docs/development.md) and run relevant browser checks for interaction changes. State what you tested and any remaining limits.
